# 📍 Google Maps Lead Finder (No-Website Pro)

Професійний інструмент на **Node.js** для автоматичного пошуку та збору контактів бізнесів із **Google Maps**, які **не мають власного веб-сайту** (або мають лише посилання на Instagram, Facebook, Booking.com, онлайн-запис Altegio/Dikidi тощо).

---

## ✨ Можливості програми

1. **Гнучкий вибір категорій бізнесу:**
   - Готові пресети в один клік: *Салони краси, Барбершопи, Ресторани, Кафе, Готелі та садиби, СТО, Автомийки, Стоматології, Спортзали, Шиномонтаж*.
   - Можливість ввести будь-яку власну категорію (*наприклад, «йога студія», «ремонт взуття», «квітковий магазин»*).

2. **Точна географічна фільтрація:**
   - Всі 24 області України у зручному випадаючому списку.
   - Автопідказки міст та районів при виборі області.
   - Можливість шукати в будь-якому конкретному місті, селищі чи районі.

3. **Інтелектуальна класифікація веб-ресурсів:**
   - ❌ **«Сайт відсутній зовсім»** — бізнес не вказав жодного посилання.
   - 📱 **«Сторонній сервіс / соцмережа / агрегатор»** — бізнеси без сайту, але з посиланням на:
     - **Соцмережі:** Instagram, Facebook, TikTok, Telegram, YouTube.
     - **Готелі та оренда:** Booking.com, TripAdvisor, Hotels.com, Airbnb, Agoda, Doba.ua, Karpaty.info.
     - **CRM та онлайн-запис:** Altegio / Yclients, Dikidi, EasyWeek, Bumpix, Barb.ua, BeautyPro.
     - **Меню та доставка:** Choice QR, Poster POS, Expirenza, RestOn, Glovo, Bolt Food.
     - **Мультипосилання (Link-in-bio):** Linktree, Taplink, MSSG.me, Bio.link, Beacons.
     - **Шаблони:** Google Business Site (`*.business.site`), каталоги Top20, Prom, OLX.
   - 🌐 **«Власний сайт»** — бізнеси з власним доменним сайтом автоматично відфільтровуються.

4. **Збереження бази та статус продзвону лідів:**
   - Всі знайдені контакти надійно зберігаються на сервері (`data/leads.json`) та не зникають після оновлення сторінки.
   - Можливість позначати статус: **«Не дзвонили» ⇄ «Дзвонили»** в один клік прямо в таблиці.
   - Система автоматично фіксує, **хто саме з менеджерів подзвонив** та в який точний час.

5. **Авторизація менеджерів та панель адміністратора:**
   - При першому вході менеджер вводить своє ім'я (зберігається в системі).
   - Вхід в захищену адмін-панель за паролем:
     - **Логін:** `adminsonly`
     - **Пароль:** `dolar14uero`
   - В адмінці відображається повна статистика: рейтинг менеджерів (хто скільки номерів продзвонив) та детальна стрічка останніх дзвінків.

6. **Сучасний інтерактивний веб-інтерфейс (Dashboard):**
   - Мультивибір категорій (можна обрати кілька одразу: наприклад, «Салони краси» + «Барбершопи»).
   - Жива таблиця результатів у реальному часі (SSE стрімінг).
   - 6 карток аналітики та лічильників (включно зі статусами дзвінків).
   - Пошук та фільтрація всередині таблиці (наприклад, «Лише продзвонені», «Лише нові»).
   - Кнопка швидкого копіювання всіх знайдених номерів списком.

7. **Експорт даних:**
   - 📊 **Excel (.xlsx)** — структурована таблиця з категоріями, статусами дзвінків, ім'ям менеджера та датою дзвінка.
   - 📄 **CSV (UTF-8 BOM)** — гарантовано відкривається в Excel без проблем з кодуванням.
   - 📦 **JSON** — для інтеграції з CRM або зовнішніми базами.

## 🚀 Як запустити програму локально

### Варіант 1: Запуск у 1 клік (Windows)
Просто двічі клацніть на файл:
```text
start.bat
```
Він автоматично запустить сервер та відкриє інтерфейс у браузері за адресою `http://localhost:3000`.

### Варіант 2: Запуск через термінал
```bash
npm start
```
Після цього відкрийте у браузері: [http://localhost:3000](http://localhost:3000).

## ☁️ Безкоштовний деплой на хостинг (Hugging Face Spaces)

Оскільки проєкт використовує Puppeteer (реальний веб-браузер) та зберігає базу номерів, сервери типу Vercel/Netlify не підходять (вони обмежують час роботи до 10-15 сек і не дають зберігати файли).

Найкраще 100% безкоштовне рішення — **Hugging Face Spaces** (дає 16 ГБ RAM, 2 vCPU та підтримку Docker):

1. Зареєструйтесь безкоштовно на [huggingface.co](https://huggingface.co).
2. Натисніть **New Space** (або перейдіть за посиланням https://huggingface.co/new-space).
3. Вкажіть:
   - **Space name**: наприклад `lead-hunter`
   - **License**: `mit` або `apache-2.0`
   - **Space SDK**: оберіть **Docker** (Blank)
   - **Space hardware**: `Free (2 vCPU, 16GB RAM)`
4. Завантажте файли проєкту у створений репозиторій (через вебінтерфейс кнопки **Files -> Add file -> Upload files** або через `git clone` / `git push`):
   - `Dockerfile`
   - `.dockerignore`
   - `package.json`
   - `package-lock.json`
   - `server.js`
   - папку `services/` з усіма файлами
   - папку `public/` з усіма файлами
5. Hugging Face автоматично збере Docker-образ і за кілька хвилин надасть публічне посилання на ваш робочий сайт (наприклад: `https://ваше-ім'я-lead-hunter.hf.space`).
6. Тепер ви та ваші співробітники можуть заходити з будь-якого комп'ютера чи телефона, збирати базу та разом відмічати продзвонені номери!

## 💻 Консольний режим (CLI)

Для автоматизації або швидкого вивантаження без відкриття браузера доступний консольний скрипт:

```bash
# Приклад 1: Салони краси у Львові (20 результатів в Excel)
node cli.js -c "салони краси" --city "Львів" -n 20 -o lviv_beauty.xlsx

# Приклад 2: Готелі в Одесі (лише ті, де немає посилання взагалі)
node cli.js -c "готелі" --city "Одеса" -f only_no_link -o odesa_hotels.csv

# Приклад 3: СТО в Дніпрі
node cli.js -c "СТО автосервіс" --city "Дніпро" -n 50 -o dnipro_sto.xlsx
```

## 🛠️ Стек технологій
- **Мова:** JavaScript / Node.js (v20+ / v24)
- **Бекенд:** Express.js, Server-Sent Events (SSE)
- **Браузерна автоматизація:** `puppeteer-core` (використовує встановлений Chromium або Chrome/Edge)
- **Фронтенд:** HTML5, Tailwind CSS, Vanilla JS
- **Збереження даних:** Автономне локальне сховище JSON (`data/leads.json`, `data/users.json`)
- **Контейнеризація:** Docker (ready for Hugging Face Spaces)
- **Робота з файлами:** `xlsx`
